# PRD: прошивки для ДЗ-14 (Wi-Fi + BLE)

Два пристрої на одному стенді ESP32-S3 DevKit. Прошиваються по черзі (спочатку Частина A, потім перепрошивка на Частину B).

---

## Пристрій 1: Wi-Fi станція (station_WiFi)

**Призначення:** пристрій розумного дому, що підключається до Wi-Fi мережі, вимірює відстань, керує реле і LED, вміє оновлюватись по OTA.

### Функціональні вимоги

**Wi-Fi:**
- FR-W1. `scan` показує список доступних мереж: номер, SSID, RSSI (dBm).
- FR-W2. `connect` - інтерактивний діалог: скан мережі, промпт SSID (можна ввести номер зі списку або ім'я), промпт пароля. Таймаут підключення 10 с.
- FR-W3. Пароль коротший за 8 символів відхиляється з повідомленням `password too short (min 8 chars)` без спроби підключення.
- FR-W4. При успішному підключенні креденшили зберігаються в NVS. Наступний `connect` + Enter (порожній ввід) використовує збережені. Збережене переживає reboot.
- FR-W5. `status`: якщо підключено - SSID, IP-адреса, RSSI; якщо ні - повідомлення що не підключено.
- FR-W6. `disconnect` розриває з'єднання і не робить автоматичний reconnect.
- FR-W7. При втраті мережі пристрій робить повторні спроби підключення.

**Периферія:**
- FR-P1. `distance` - безперервне вимірювання (зупинка Enter); `distance <seconds>` - N секунд. Вивід у см, при відсутності еха - `timeout`.
- FR-P2. `relay on` / `relay off` - керування реле (GPIO8). `sensor status` показує актуальний стан реле.
- FR-P3. `led on` / `led off` / `led auto` / `led rgb`. У режимі auto LED зелений при підключеному Wi-Fi, червоний при відключеному.
- FR-P4. `sysinfo`, `temp`, `sensor status` - діагностика (чіп, heap, температура, сенсори).
- FR-P5. `reboot` - перезавантаження з відліком 3-2-1.

**OTA:**
- FR-O1. `ota <url>` - завантаження app-образу по HTTP і прошивка у вільний OTA-слот, після успіху - автоматичний ребут у нову версію.
- FR-O2. `ota-test-server` - демо-оновлення з вбудованого тестового сервера (потребує Wi-Fi).

**Кнопки:**
- FR-B1. K1 (GPIO41) - вимірювання відстані 10 с.
- FR-B2. K2 (GPIO40) - перемикання реле (дзеркало `relay on/off`).
- FR-B3. K3 (GPIO39) - якщо підключено: disconnect; якщо ні: reconnect по збережених креденшилах.
- FR-B4. K4 (GPIO38) - перемикання діода (GPIO4).
- FR-B5. Кожне натискання логується: `button N pressed (GPIOxx)`.

## Пристрій 2: BLE GATT-сервер (SENTRY-BLE)

**Призначення:** BLE-периферійний пристрій (датчик пульсу + виконавчі механізми), керується з BLE-central (телефон/ноутбук) і дублює всі події в UART-лог.

### Функціональні вимоги

**Реклама і з'єднання:**
- FR-A1. Пристрій рекламується під іменем `SENTRY-BLE`, доступний для підключення.
- FR-A2. Після розриву з'єднання реклама відновлюється автоматично (пристрій можна знайти знову без ребута).
- FR-A3. Підключення/відключення логуються в UART: `Connected, conn_id ..., remote <MAC>` / `Disconnected ...`.

**GATT:**
- FR-G1. Heart Rate Service `0x180D` з характеристикою `0x2A37` (read + indicate). Пульс оновлюється щосекунди, нормальний діапазон 60-80 bpm.
- FR-G2. Підписка на indications через CCCD: після підписки клієнт отримує оновлення пульсу щосекунди.
- FR-G3. Automation IO Service `0x1815` з двома характеристиками (128-бітні UUID):
  - LED `00001525-1212-efde-1523-785feabcd123` (read/write)
  - RELAY `00001526-1212-efde-1523-785feabcd123` (read/write)
- FR-G4. Write 0x01/0x00 у LED/RELAY вмикає/вимикає фізичний LED / реле (GPIO8) і пише в UART `LED ON!`/`LED OFF!` або `RELAY ON!`/`RELAY OFF!`.
- FR-G5. Read LED/RELAY повертає актуальний стан (1 байт: 0 або 1), включно з випадком, коли стан змінили локально (кнопкою або CLI).

**UART CLI:**
- FR-C1. Команди: `help`, `status`, `led on/off`, `relay on/off`, `hr spike`, `adv restart`, `disconnect`, `reboot`.
- FR-C2. `status` показує: ім'я пристрою, стан BLE (connected + MAC клієнта / not connected + advertising), поточний пульс, стан LED, стан реле, uptime.
- FR-C3. `hr spike` (і кнопка K1) інжектить аномальний пульс ~190-199 bpm на 5 секунд - для перевірки реакції клієнта на позаштатні значення.
- FR-C4. Невідома команда - `unknown command: '...' (type 'help')`.
- FR-C5. Boot-маркер: `[Boot] Device ready. Type 'help' for commands`.

**Кнопки:**
- FR-K1. K1 (GPIO41) - heart rate spike.
- FR-K2. K2 (GPIO40) - LED toggle локально (без BLE).
- FR-K3. K3 (GPIO39) - розрив BLE-з'єднання, якщо є; інакше - рестарт реклами.
- FR-K4. K4 (GPIO38) - relay toggle локально.

### Важлива особливість архітектури

LED і реле мають **три канали керування**: BLE write, UART-команда, кнопка. Всі три працюють з одним фізичним станом. Це джерело цікавих тестових сценаріїв (наприклад: BLE увімкнув LED, кнопка вимкнула - що поверне BLE read?).
