# HomeTherm v2 — HIL Test Stand & E2E Test Suite

Даний репозиторій містить повний комплект документації, схем та архітектури автоматизованого HIL-стенду (Hardware-in-the-Loop) для тестування розумного термостата **HomeTherm v2** на базі мікроконтролера **SENTRY-C1 (ESP32-S3)**.

## Основні характеристики стенду
* **DUT:** SENTRY-C1 (ESP32-S3).
* **Концепція сенсора:** Застосовано **Sensor Emulation** — ультразвуковий датчик відстані US-100 емулює показники температури для прискорення та безпеки тестування.
* **Автоматизація живлення (NFR-3):** USB-реле LCUS-1/LCUS-2 (CH340) для симуляції аварійного вимкнення 5V.
* **Канал логування:** Адаптер CP2102 USB-UART, підключений до GPIO43 (TX) та GPIO44 (RX) на швидкості 115200 8N1.
* **Тестовий фреймворк:** PyTest з автовизначенням COM-портів за VID/PID.
