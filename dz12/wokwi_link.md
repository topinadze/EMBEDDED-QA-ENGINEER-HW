# Wokwi Simulation Model — HomeTherm v2

## Посилання на онлайн-модель
* **Wokwi Project Link:** https://wokwi.com/projects/475071586034473985

## Скріншоти роботи симуляції

### 1. Режим нагріву (HEATING ON)
* **Умова:** Відстань $2\text{ см} < 20\text{ см}$ (поріг).
* **Стан:** Зелений LED увімкнений (PASS/HEAT), реле замкнене, на OLED виведено `Status: HEATING ON`.

![Wokwi Simulation HEATING ON](./screenshots/Screenshot%202026-09-14%20132926.png)

### 2. Режим очікування / вимкнено (HEATING OFF)
* **Умова:** Відстань $56\text{ см} \ge 20\text{ см}$ (поріг).
* **Стан:** Зелений LED вимкнений, реле розімкнене, на OLED виведено `Status: HEATING OFF`.

![Wokwi Simulation HEATING OFF](./screenshots/Screenshot%202026-09-14%20132935.png)

## Опис симульованого сценарію
Модель повністю реалізує та демонструє виконання функціональних вимог **FR-1**, **FR-2** та **FR-4**:
1. **Зчитування даних:** Опитування ультразвукового датчика US-100 (GPIO5 Trig / GPIO18 Echo).
2. **Візуалізація:** Вивід системного заголовка, поточного значення та статусу роботи на OLED-дисплей SSD1306 через I2C (GPIO1 SDA / GPIO2 SCL).
3. **Керування та Індикація:** Перемикання стану опалювального реле на GPIO8 та відповідних світлодіодів стану (GPIO4 Жовтий - RUN, GPIO6 Зелений - HEAT ON).
