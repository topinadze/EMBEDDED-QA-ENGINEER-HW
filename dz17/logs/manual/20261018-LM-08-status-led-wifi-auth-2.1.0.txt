The operator confirmed that all four combinations were observed on firmware 2.1.0 and that the indicator was the board's built-in RGB LED. These are visual descriptions; no colorimetric measurement was made.

Related command readback:
- After local login, `lamp status` returned `[BEACON] off, color (255,0,0), brightness 100%, mode solid, timer off`.
- The command reports the beacon's logical on/off state and configured color. It does not, by itself, describe the physical status-indicator color being displayed while the beacon is off.

Assessment:
- The observations are consistent with LM-8's general requirement that the RGB LED show system status while the lamp is off.
- PRD §6 / LM-8 specifies indicator priority but does not define these specific colors or map them to Wi-Fi/login combinations. Treat the matrix as observed behavior, not yet as a normative contract or a confirmed defect.
- Detailed confirmation of each LED priority override and the exact Wi-Fi/auth color mapping remains open.
