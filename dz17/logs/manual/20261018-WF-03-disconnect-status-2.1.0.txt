This confirms synchronization after that later manual reconnect, not when or whether it recovered before the sequence. Exact clock values and network identifiers are redacted.

A subsequent manual `reconnect` restored association, IP and internet reachability, but again returned W106 because NTP synchronization failed. This does not test loss of connection without an operator command or WF-5's W110/automatic retries.
- In a later already-connected state, issuing `reconnect` returned the specified `W114 already connected`; subsequent telemetry continued in NORMAL. No disconnect/reconnect action followed this W114 response.
- Result is partial WF-3 evidence for firmware 2.1.0.
